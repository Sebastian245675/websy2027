**Desarrollar la página web de una empresa implica decidir cinco cosas: qué tipo de sitio necesitas (landing, institucional, tienda, aplicación web), con qué tecnología construirlo (un CMS como WordPress, un constructor, o desarrollo moderno con React y Next.js), cómo será el diseño y la experiencia de uso, cómo se va a encontrar en Google y quién lo va a mantener.** El proceso habitual es relevamiento, estructura y contenido, diseño en prototipo, desarrollo, pruebas, publicación y mejora continua.

Esta guía ordena todas esas decisiones para que puedas planificar tu web, entender lo que te propone un proveedor y evitar los errores más caros. Al final están todos los artículos de la guía con el detalle de cada tema.

## Qué tipo de sitio necesitas

| Tipo | Para qué sirve | Ejemplo |
| --- | --- | --- |
| Landing page | Una sola acción: consulta, venta o registro | Campaña de un servicio puntual |
| Sitio institucional | Presentar la empresa, sus servicios y captar consultas | Estudio jurídico, consultora, industria |
| Tienda online | Vender productos con pago y envío | Comercio minorista o mayorista |
| Aplicación web | Que los usuarios hagan tareas: reservar, gestionar, consultar | Sistema de turnos, portal de clientes |
| Plataforma | Varios tipos de usuarios interactuando | Marketplace, campus virtual |

Si dudas entre un sitio y una aplicación, mira [diferencia entre página web y aplicación web](/blog/diferencia-entre-pagina-web-y-aplicacion-web-cual-necesito).

## Qué tecnología usar

| Opción | Ventajas | Límites | Conviene para |
| --- | --- | --- | --- |
| Constructor (Wix, Squarespace) | Rápido, editable por uno mismo | Control limitado, abono mensual | Presencia simple |
| WordPress | Muy conocido, muchos plugins | Mantenimiento de plugins, velocidad variable | Sitios con mucho contenido editorial |
| Desarrollo moderno (React, Next.js) | Velocidad, diseño propio, SEO técnico controlado | Requiere un equipo de desarrollo | Empresas que quieren diferenciarse y posicionar |
| Plataforma de e-commerce | Tienda lista | Plantillas y comisiones | Tiendas que empiezan |

Comparaciones en [React vs WordPress](/blog/desarrollo-web-react-vs-wordpress-guia-comparativa), [qué es React](/blog/que-es-react-javascript-framework-para-que-sirve), [qué es Next.js](/blog/next-js-que-es-por-que-usarlo-para-tu-pagina-web) y [qué es un headless CMS](/blog/desarrollo-web-jamstack-headless-cms-nextjs).

## El proceso, paso a paso

1. **Relevamiento**: objetivos, público, competencia, servicios, qué tiene que lograr la web.
2. **Estructura y contenido**: mapa del sitio (una página por servicio), textos, fotos reales.
3. **Diseño**: prototipo en Figma que se aprueba antes de programar. Ver [qué es el diseño UX/UI](/blog/diseno-ux-ui-que-es-por-que-importa-para-tu-negocio).
4. **Desarrollo**: maquetado responsive, formularios, integraciones (WhatsApp, CRM, pagos), SEO técnico.
5. **Pruebas**: en celulares reales, velocidad, formularios, enlaces.
6. **Publicación**: dominio, HTTPS, Search Console, analítica.
7. **Mejora continua**: medir consultas, ajustar textos, sumar contenido.

En Websy, una landing page lleva 5 a 7 días hábiles y un sitio institucional 2 a 3 semanas, desde USD 800.

## Diseño y experiencia de uso

Una web que vende es clara antes que linda:

- **Mensaje principal** que diga qué haces, para quién y dónde.
- **Diseño adaptado al celular**, donde llega la mayoría de las visitas. Ver [diseño web responsive](/blog/diseno-web-responsive-que-es-por-que-es-obligatorio).
- **Contacto inmediato**: WhatsApp y formulario corto. Ver [formulario de contacto que convierte](/blog/como-disenar-un-formulario-de-contacto-de-alta-conversion).
- **Accesibilidad**: contraste, tamaños de letra, navegación con teclado. Ver [accesibilidad web WCAG](/blog/accesibilidad-web-wcag-que-es-como-implementarla).
- **Identidad visual coherente**: logo, colores, tipografías. Ver [psicología del color en diseño web](/blog/psicologia-del-color-en-diseno-web-y-conversion-de-ventas) y [cómo diseñar un logo profesional](/blog/como-disenar-logo-profesional-para-empresa-guia-branding).

## Velocidad

La velocidad afecta las ventas y el posicionamiento. Las mejoras con más impacto: imágenes en formatos modernos con tamaño declarado, poco JavaScript en la carga inicial, fuentes optimizadas, buen hosting con CDN. Ver [cómo mejorar la velocidad de carga](/blog/velocidad-de-carga-web-como-optimizar-pagespeed-100) y [qué son las Core Web Vitals](/blog/core-web-vitals-como-optimizar-velocidad-web-posicionamiento-google).

## SEO desde el desarrollo

El SEO técnico se resuelve mejor al construir la web que después: URLs limpias, una canonical por página, contenido en el HTML, datos estructurados, sitemap automático y velocidad. Ver la [guía de SEO y marketing digital](/blog/guia-seo-y-marketing-digital-para-pymes).

## Errores más caros

- **Empezar a programar sin contenido**: los textos son la causa número uno de demoras.
- **Diseñar para computadora** y adaptar al celular al final.
- **Una sola página para todos los servicios**.
- **El dominio a nombre del proveedor**.
- **No medir** consultas ni conversiones.

Más en [errores al crear una página web](/blog/errores-comunes-al-crear-pagina-web-empresa-como-evitarlos).

## Preguntas frecuentes

### ¿Cuánto cuesta desarrollar una página web para una empresa?

En Websy, una landing page o un sitio institucional arranca en USD 800; una tienda online va de USD 1.800 a 3.500. Ver la [guía de precios](/blog/precios-desarrollo-web-apps-y-software-latam).

### ¿Cuánto tarda hacer una página web?

Una landing page, 5 a 7 días hábiles; un sitio institucional, 2 a 3 semanas; una tienda online, 3 a 6 semanas.

### ¿WordPress o una web a medida?

WordPress conviene para sitios con mucho contenido editorial y presupuesto ajustado; una web a medida con React o Next.js, para velocidad, diseño propio y SEO técnico controlado.

### ¿Puedo editar mi web después?

Sí. Se puede entregar con un panel o un CMS para editar textos, fotos y precios sin tocar código.
