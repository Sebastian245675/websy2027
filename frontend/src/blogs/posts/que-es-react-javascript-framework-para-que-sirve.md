**React** (también llamado React.js) es una biblioteca de JavaScript creada por Facebook en 2013 para construir interfaces de usuario. Hoy es la tecnología #1 del desarrollo web: la usan Facebook, Instagram, WhatsApp Web, Netflix, Airbnb, Uber, y miles de empresas más.

---

## ¿Qué hace React?

React se encarga de la **parte visual** de un sitio web o aplicación: botones, menús, formularios, listas, tarjetas, modales... todo lo que el usuario ve e interactúa.

---

## ¿Por qué React es tan popular?

### 1. Componentes Reutilizables
En vez de escribir código repetitivo, creás **componentes** (piezas de interfaz) que podés reutilizar en toda la aplicación. Un botón, una tarjeta de producto, un formulario: se crean una vez y se usan en todas partes.

### 2. Virtual DOM (Rendimiento Ultra Rápido)
React actualiza solo las partes de la página que cambian, no toda la página completa. Esto hace que las interfaces se sientan instantáneas.

### 3. Ecosistema Masivo
Miles de librerías complementarias: React Router (navegación), Redux (estado global), Framer Motion (animaciones), Material UI (componentes pre-diseñados).

### 4. Mercado Laboral
React es la habilidad #1 más demandada en desarrollo web. Hay más ofertas de trabajo para React que para cualquier otro framework.
