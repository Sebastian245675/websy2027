La arquitectura **Jamstack (JavaScript, APIs, Markup)** ha transformado radicalmente el desarrollo de software web empresarial. 

En lugar de procesar cada visita en servidores monolíticos lentos, Jamstack pre-compila el sitio web en archivos HTML estáticos ultra rápidos y los conecta con servicios backend a través de APIs REST o GraphQL.

---

## 1. ¿Qué es un Headless CMS?

Un **Headless CMS** (como Strapi, Sanity o Contentful) es un gestor de contenidos que "desacopla" la cabeza (la interfaz visual frontend) del cuerpo (la base de datos y la administración de contenidos).

- Los redactores cargan productos o noticias en el panel del Headless CMS.
- El sitio web en React / Next.js consume esos datos por API y genera páginas estáticas instantáneas.
