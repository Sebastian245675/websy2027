## Cómo busca un cliente un servicio de limpieza

El cliente busca "house cleaning near me", "move out cleaning Miami" u "office cleaning Houston". Compara dos o tres empresas por tres cosas: **reseñas, precio aproximado y rapidez de respuesta**. Muchas veces escribe a varias a la vez y se queda con la primera que le da un precio claro.

Por eso la web tiene que contestar las preguntas antes de que el cliente tenga que hacerlas.

## Qué tiene que tener la web

### Una página por tipo de limpieza

| Servicio | Lo que busca el cliente |
| --- | --- |
| Limpieza residencial regular | "house cleaning", "maid service", frecuencia semanal o quincenal |
| Limpieza profunda | "deep cleaning", primera limpieza o limpieza de temporada |
| Limpieza de mudanza | "move in / move out cleaning", con fecha fija |
| Limpieza de oficinas | "office cleaning", "commercial cleaning", contrato mensual |
| Post construcción | "post construction cleaning", después de una obra |

Cada uno es una búsqueda distinta. Con una página para cada uno, puedes aparecer en todas.

### Cómo se calcula el precio

No hace falta publicar una tarifa exacta, pero sí explicar de qué depende: cantidad de habitaciones y baños, frecuencia y tipo de limpieza. Mejor aún, un **formulario que pida esos datos** y devuelva una estimación o una cotización rápida.

### Confianza

- **Reseñas** de clientes reales, con enlace a tu perfil de Google.
- **Seguro y garantía**: qué pasa si algo se rompe o si el cliente no queda conforme.
- **Quiénes limpian**: si el personal está verificado y capacitado.
- **Productos**: si usan productos ecológicos o el cliente puede pedir los suyos.

### Reserva simple

Botón de llamada, mensaje de texto y WhatsApp siempre visible en el celular, y un formulario corto. Si manejas mucho volumen, un sistema de reservas con horarios disponibles ahorra llamadas.

## Clientes fijos: el verdadero negocio

En limpieza, el cliente que vale es el que vuelve cada semana o cada dos. La web puede ayudar a convertir una limpieza única en un cliente fijo:

- Mostrar el **descuento por frecuencia** (semanal, quincenal, mensual).
- Ofrecer el plan fijo en la confirmación de la primera limpieza.
- Enviar un recordatorio automático para reagendar.

## Errores comunes

- **No dar ninguna idea del precio.** El cliente se va a la empresa que sí lo explica.
- **Una sola página para todos los servicios.**
- **Fotos de banco** de personas limpiando. Muestra a tu equipo y tus trabajos.
- **Formularios largos.** Bastan el tipo de limpieza, el tamaño de la casa, la fecha y el contacto.
- **Tardar en responder.** En limpieza, la primera respuesta gana.
