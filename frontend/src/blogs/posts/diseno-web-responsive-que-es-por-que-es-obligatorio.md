**El diseño web responsive es la forma de construir una web para que se adapte automáticamente a cualquier pantalla (celular, tablet, computadora), reorganizando el contenido, el tamaño de los textos y las imágenes para que siempre se lea y se use cómodamente.** Es obligatorio en la práctica: la mayoría de las visitas llegan desde el celular y Google indexa y evalúa las webs principalmente en su versión móvil (indexación mobile-first).

En esta guía verás cómo funciona el diseño responsive, por qué conviene diseñar primero para el celular, los elementos que más fallan en móvil, cómo probar tu web y un checklist.

## Cómo funciona

| Técnica | Qué hace |
| --- | --- |
| Diseño fluido | Los elementos se miden en proporciones, no en píxeles fijos |
| Media queries | Reglas de CSS que cambian el diseño según el ancho de la pantalla |
| Imágenes adaptables | Se sirve una imagen del tamaño adecuado para cada pantalla |
| Grillas flexibles (Flexbox, Grid) | Las columnas se reorganizan: tres en computadora, una en celular |
| Tipografía adaptable | Tamaños que se ajustan a la pantalla |

## Mobile-first: diseñar primero para el celular

Diseñar primero para el celular obliga a priorizar: en una pantalla chica entra lo esencial. Después, en pantallas grandes, se suma espacio y detalle. El camino inverso (diseñar para computadora y "achicar") suele dejar menús ilegibles, textos diminutos y botones imposibles de tocar.

## Por qué es obligatorio

- **Tus clientes están en el celular**: la mayoría del tráfico de una pyme llega desde el teléfono, sobre todo desde redes y WhatsApp.
- **Google evalúa la versión móvil**: con la indexación mobile-first, lo que no está o no funciona en el celular, no cuenta.
- **Conversiones**: si contactarte o comprar es difícil en el celular, se pierden ventas.
- **Velocidad**: el diseño responsive bien hecho sirve imágenes livianas en el celular.

## Lo que más falla en el celular

| Problema | Solución |
| --- | --- |
| Textos muy chicos | Tamaño base legible (alrededor de 16 px) |
| Botones pegados o pequeños | Áreas táctiles amplias y separadas |
| Menús que no se abren o tapan todo | Menú simple, probado en pantallas chicas |
| Tablas que se salen de la pantalla | Desplazamiento horizontal dentro de la tabla o diseño en tarjetas |
| Ventanas emergentes que tapan el contenido | Evitarlas o que se cierren fácilmente |
| Formularios incómodos | Campos grandes, teclado adecuado (numérico para teléfonos) |
| WhatsApp o teléfono difíciles de encontrar | Botón fijo visible |

## Cómo probar tu web en el celular

1. **Ábrela en tu teléfono** y en el de alguien con una pantalla más chica.
2. **Usa el modo de dispositivo** de las herramientas del navegador para probar distintos tamaños.
3. **Haz las tareas principales**: encontrar un servicio, contactar, comprar.
4. **Revisa PageSpeed Insights** en la vista móvil.
5. **Revisa Search Console** por problemas de usabilidad o de Core Web Vitals en móvil.

## Puntos de quiebre habituales

| Rango de ancho | Dispositivo típico | Qué cambia |
| --- | --- | --- |
| Hasta 640 px | Celulares | Una columna, menú desplegable, botones de ancho completo |
| 640 a 1024 px | Tablets y celulares en horizontal | Dos columnas, más espacio |
| Más de 1024 px | Computadoras | Varias columnas, menú completo |

Los puntos de quiebre se eligen según el contenido, no según modelos de teléfono: el diseño cambia donde el contenido empieza a verse mal.

## Preguntas frecuentes

### ¿Qué es el diseño web responsive?

Una forma de construir webs que se adaptan automáticamente al tamaño de cada pantalla para que se lean y se usen bien en celulares, tablets y computadoras.

### ¿Por qué es importante que una web sea responsive?

Porque la mayoría de las visitas llegan desde el celular y Google evalúa principalmente la versión móvil de las webs.

### ¿Responsive y mobile-first es lo mismo?

No exactamente. Responsive es que se adapte; mobile-first es diseñar primero para el celular y después ampliar a pantallas grandes.

### ¿Cómo sé si mi web es responsive?

Ábrela en distintos teléfonos y en el modo de dispositivo del navegador, y verifica que no haya que hacer zoom ni desplazarse de costado.
