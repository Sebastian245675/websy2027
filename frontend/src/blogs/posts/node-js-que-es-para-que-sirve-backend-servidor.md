**Node.js** es un entorno de ejecución que permite usar JavaScript (el lenguaje del navegador) para construir el **servidor** (backend) de aplicaciones web. Fue creado en 2009 y hoy lo usan LinkedIn, Netflix, PayPal, Walmart, NASA, Trello y miles de empresas más.

---

## ¿Qué hace Node.js?

Mientras React se encarga de lo que **ve** el usuario (frontend), Node.js se encarga de lo que **no ve**: autenticación de usuarios, procesamiento de pagos, consultas a la base de datos, envío de emails, interacción con APIs externas.

---

## ¿Por qué Node.js es tan popular?

### 1. JavaScript Full-Stack
Con Node.js, podés usar el mismo lenguaje (JavaScript) tanto en el frontend como en el backend. Un solo programador puede trabajar en todo el proyecto.

### 2. Rendimiento con I/O No-Bloqueante
Node.js maneja miles de conexiones simultáneas sin crear un hilo por cada una. Es perfecto para apps de chat, notificaciones en tiempo real y APIs de alta concurrencia.

### 3. NPM: El Ecosistema de Paquetes más Grande del Mundo
NPM tiene más de 2 millones de paquetes (librerías) gratuitos para cualquier funcionalidad imaginable: envío de emails, procesamiento de imágenes, autenticación, pagos.

### 4. Empresas que lo Eligieron
- **Netflix**: Migró de Java a Node.js y redujo el tiempo de inicio de su app un 70%.
- **LinkedIn**: Migró de Ruby on Rails a Node.js y pasó de 30 servidores a 3.
- **PayPal**: Migró de Java a Node.js y duplicó las requests por segundo con menos código.

---

## ¿Cuándo usar Node.js?

| ✅ Ideal para | ❌ No ideal para |
| --- | --- |
| APIs REST y GraphQL | Procesamiento intensivo de CPU (video encoding) |
| Apps en tiempo real (chat, gaming) | Machine Learning pesado |
| Microservicios | Sistemas legacy enterprise |
| E-commerce y SaaS | Aplicaciones científicas/matemáticas |
