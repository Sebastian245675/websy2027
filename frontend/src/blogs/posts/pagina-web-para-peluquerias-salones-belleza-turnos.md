## Funcionalidades para una Web de Peluquería

### 1. Sistema de Turnos por Servicio y Profesional
El cliente elige: servicio (corte, color, alisado, barbería), profesional, fecha y horario disponible. Recibe confirmación instantánea por WhatsApp.

### 2. Lista de Servicios con Precios
Cada servicio con descripción, duración estimada y precio. Elimina la pregunta "¿Cuánto sale?" que satura tu WhatsApp.

### 3. Galería "Antes y Después"
Fotos de transformaciones reales que demuestran la calidad del trabajo. El contenido visual vende mucho más que las palabras.

### 4. Perfil de cada Profesional
Foto, especialidad y años de experiencia. Los clientes frecuentemente eligen a su estilista por afinidad personal.

### 5. Promociones y Packs
Sección de ofertas combinadas ("Corte + Color: $X en vez de $Y") con temporizador de urgencia.
