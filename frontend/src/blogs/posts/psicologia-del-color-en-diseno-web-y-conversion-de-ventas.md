**La psicología del color en diseño web estudia cómo los colores influyen en la percepción de una marca y en las acciones de los visitantes; en la práctica, lo que más impacto tiene en la conversión no es un color "mágico", sino el contraste: que el botón o la acción principal se distinga claramente del resto de la página, con un color que la marca reserve para eso.** Las asociaciones de cada color (azul con confianza, verde con salud o dinero, rojo con urgencia) existen, pero dependen de la cultura, el rubro y el contexto.

En esta guía verás las asociaciones habituales de cada color, cómo armar una paleta para una web, cómo usar el color para guiar la atención y la conversión, las reglas de contraste y accesibilidad, y los errores más comunes.

## Asociaciones habituales de los colores

| Color | Asociaciones frecuentes | Rubros donde se usa mucho |
| --- | --- | --- |
| Azul | Confianza, seguridad, profesionalismo | Finanzas, tecnología, salud, servicios profesionales |
| Verde | Salud, naturaleza, crecimiento, dinero | Salud, alimentos, sustentabilidad, finanzas |
| Rojo | Energía, urgencia, pasión | Gastronomía, ofertas, entretenimiento |
| Naranja | Entusiasmo, accesibilidad, acción | Comercio, llamados a la acción |
| Amarillo | Optimismo, atención | Destacados, señalización |
| Violeta | Creatividad, lujo, espiritualidad | Belleza, bienestar, marcas premium |
| Negro | Elegancia, lujo, sobriedad | Moda, productos premium |
| Blanco y neutros | Limpieza, simplicidad, espacio | Base de casi cualquier web |

Son tendencias, no reglas: el significado cambia con la cultura, el tono exacto y lo que hace la competencia.

## Cómo armar la paleta de una web

Una estructura simple y efectiva:

| Rol | Proporción aproximada | Uso |
| --- | --- | --- |
| Neutros (fondos, textos) | Mayoría de la superficie | Base legible |
| Color de marca principal | Una parte menor | Identidad, encabezados, elementos destacados |
| Color de acento | Muy poco, reservado | Botones de acción principal |
| Colores de estado | Solo cuando corresponde | Éxito, error, advertencia |

La regla clave: el color de acento se usa solo para la acción principal. Si todo es del mismo color llamativo, nada se destaca.

## Color y conversión

- **Contraste del botón**: el llamado a la acción tiene que ser el elemento más visible de la sección.
- **Consistencia**: el mismo color para la misma acción en todo el sitio.
- **Jerarquía**: acción principal con color de acento, acciones secundarias con estilo más discreto.
- **Probar**: el color ganador depende de tu diseño; un test A/B lo confirma. Ver [qué es CRO](/blog/cro-conversion-rate-optimization-guia-testing-ab).

No existe un "color de botón que más vende" universal: un botón rojo puede convertir mejor en una página azul y peor en una página roja.

## Contraste y accesibilidad

Las pautas WCAG recomiendan una relación de contraste mínima de 4,5:1 para texto normal y 3:1 para texto grande y elementos de interfaz. Un texto gris claro sobre fondo blanco puede verse elegante en la pantalla del diseñador y ser ilegible en un celular al sol. Ver [accesibilidad web WCAG](/blog/accesibilidad-web-wcag-que-es-como-implementarla).

Además, no comunicar información solo con color: un campo con error debe tener también un mensaje o un ícono, porque algunas personas no distinguen ciertos colores.

## Errores comunes

- **Demasiados colores** sin una jerarquía clara.
- **El color de acento en todo**: decoraciones, íconos, títulos y botones.
- **Bajo contraste** en textos y botones.
- **Copiar la paleta de la competencia** y perder diferenciación.
- **Ignorar el modo oscuro** si la web lo ofrece.

## Ejemplo de paleta para una web de servicios

| Rol | Color | Uso |
| --- | --- | --- |
| Fondo | Blanco y un gris muy claro | Secciones alternadas |
| Texto | Gris muy oscuro | Párrafos y títulos |
| Marca | Azul profundo | Encabezado, pie, íconos |
| Acento | Naranja | Solo el botón de WhatsApp o "Pedir presupuesto" |
| Estado | Verde y rojo | Confirmaciones y errores de formularios |

El naranja contrasta con el azul de la marca, así que el botón de acción se ve primero.

## Preguntas frecuentes

### ¿Qué color convierte más en un botón?

El que más contrasta con el resto de la página y se reserva para la acción principal. No hay un color universal; conviene probarlo.

### ¿Qué colores transmiten confianza en una web?

El azul y los neutros son los más asociados a confianza y profesionalismo, pero la confianza depende más del contenido, las pruebas y la claridad que del color.

### ¿Cuántos colores debe tener una web?

Pocos: neutros como base, un color de marca, un color de acento para las acciones y los colores de estado.

### ¿Qué contraste necesita el texto?

Al menos 4,5:1 para texto normal y 3:1 para texto grande, según las pautas WCAG.
