## ¿Cuál recomendamos en Websy?

- **PostgreSQL**: Para el 80% de los proyectos. Es la base de datos más versátil, robusta y con mejor soporte de tipos de datos avanzados (JSON, arrays, geoespacial).
- **MySQL**: Para proyectos WordPress o cuando el equipo ya tiene expertise en MySQL.
- **MongoDB**: Para IoT, catálogos de productos con atributos variables, o cuando la estructura de datos cambia frecuentemente.
