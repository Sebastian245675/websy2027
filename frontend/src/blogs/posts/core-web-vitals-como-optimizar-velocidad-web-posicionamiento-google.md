Google ha dejado perfectamente claro su criterio de ordenamiento: **los sitios web más rápidos y estables ocupan los primeros lugares de búsqueda**. 

Las métricas **Core Web Vitals** son los indicadores oficiales que Google utiliza para medir empíricamente la experiencia de usuario en tu sitio web.

---

## 1. Las 3 Métricas Oficiales de Core Web Vitals

### A. LCP (Largest Contentful Paint) - Velocidad de Carga del Elemento Principal
Mide el tiempo que tarda en cargarse el bloque de contenido visual más grande de la pantalla (generalmente la imagen principal del Hero o el título H1).
- **Objetivo Ideal**: Menos de 2.5 segundos.

### B. INP (Interaction to Next Paint) - Responsividad e Interactividad
Reemplazó oficialmente a FID. Mide cuánto tarda la página en responder visualmente cuando un usuario hace clic en un botón, menú o campo de entrada.
- **Objetivo Ideal**: Menos de 200 milisegundos.

### C. CLS (Cumulative Layout Shift) - Estabilidad Visual
Mide si los elementos de la página saltan o se mueven inesperadamente mientras cargan (por ejemplo, cuando un anuncio o imagen sin dimensiones salta y hace que el usuario haga clic por error en el botón equivocado).
- **Objetivo Ideal**: Puntuación menor a 0.1.

## 2. Técnicas Prácticas de Optimización aplicadas en Websy

1. **Formatos de Imagen de Nueva Generación (WebP / AVIF)**: Compresión de imágenes sin pérdida de calidad visual, reduciendo el peso de 3 MB a apenas 80 KB.
2. **Carga Diferida (Lazy Loading)**: Las imágenes que están abajo en la pantalla solo se descargan cuando el usuario se desplaza hacia ellas.
3. **Eliminación de CSS y JavaScript Bloqueante**: Minificación y carga asíncrona de scripts.
