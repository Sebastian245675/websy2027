## ¿Qué es Next.js en palabras simples?

Es una herramienta para construir sitios web y aplicaciones web basada en **React** (la librería de interfaces de Facebook). Agrega funcionalidades críticas que React solo no tiene:

1. **Server-Side Rendering (SSR)**: Las páginas se generan en el servidor antes de enviarlas al navegador → SEO perfecto + carga ultra rápida.
2. **Static Site Generation (SSG)**: Las páginas se generan una sola vez al construir el sitio → velocidad extrema (páginas pre-renderizadas).
3. **Rutas automáticas**: Crear un archivo = crear una página. Sin configuración de routing manual.
4. **Optimización automática de imágenes**: Next.js comprime y redimensiona imágenes automáticamente.
5. **API Routes**: Podés crear tu backend API dentro del mismo proyecto Next.js.
