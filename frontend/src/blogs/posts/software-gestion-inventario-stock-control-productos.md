El 43% de las PyMEs no controlan su inventario correctamente, lo que genera dos problemas graves: **sobrestock** (capital inmovilizado en mercadería que no se vende) y **quiebre de stock** (perder ventas porque el producto no está disponible).

---

## ¿Qué hace un Software de Gestión de Inventario?

### 1. Control de Stock en Tiempo Real
Dashboard que muestra la cantidad exacta de cada producto en cada depósito/sucursal. Se actualiza automáticamente con cada venta y cada compra.

### 2. Alertas de Stock Mínimo
El sistema envía una notificación automática por email o WhatsApp cuando un producto alcanza el punto de reposición configurado.

### 3. Múltiples Depósitos y Transferencias
Si tenés un depósito central y 3 sucursales, el sistema permite registrar transferencias entre ubicaciones y ver el stock de cada una.

### 4. Lectora de Código de Barras / QR
Escanear el código del producto con el celular para registrar entradas y salidas de mercadería sin tipear nada manualmente.

### 5. Reportes y Análisis
- Productos más vendidos por período.
- Rotación de inventario (cuántos días promedio tarda en venderse cada producto).
- Valorización del stock total.
- Historial de movimientos por producto.

---

## Hoja de Cálculo vs. Software de Inventario

| Criterio | Excel / Google Sheets | Software de Inventario |
| --- | --- | --- |
| **Actualización** | Manual (se olvida) | Automática en tiempo real |
| **Múltiples usuarios** | Conflictos de edición | Multiusuario con roles |
| **Alertas** | No tiene | Automáticas por email/WhatsApp |
| **Código de barras** | No | Sí |
| **Reportes** | Manuales (tablas dinámicas) | Automáticos con gráficos |
| **Historial** | Se pierde o sobreescribe | Registro completo inmutable |
