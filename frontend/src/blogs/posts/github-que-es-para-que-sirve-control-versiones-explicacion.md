**GitHub** es la plataforma donde el mundo guarda, gestiona y colabora en código fuente. Más de 100 millones de desarrolladores la usan, incluyendo los equipos de Google, Microsoft, Facebook, Apple y Amazon.

Si contratás desarrollo de software y tu proveedor no usa GitHub (o equivalente), es una señal de alerta enorme.

---

## ¿Qué es Git vs. GitHub?

- **Git**: Sistema de control de versiones. Registra cada cambio que se hace en el código, quién lo hizo y cuándo. Permite volver atrás si algo se rompe.
- **GitHub**: Plataforma web que aloja repositorios Git en la nube, con herramientas de colaboración (pull requests, code reviews, issues).

---

## ¿Por qué es indispensable?

### 1. Historial Completo de Cambios
Cada línea de código tiene un registro de quién la escribió, cuándo y por qué. Si algo se rompe, podés volver a la versión que funcionaba en 30 segundos.

### 2. Trabajo en Equipo sin Conflictos
Múltiples programadores pueden trabajar en el mismo proyecto simultáneamente sin sobreescribirse el código entre sí.

### 3. Código Seguro en la Nube
Tu código está respaldado en los servidores de GitHub. Si se rompe tu computadora, no perdés nada.

### 4. Propiedad del Código
Cuando tu proveedor entrega el proyecto, te transfiere la propiedad del repositorio en GitHub. Tenés acceso completo al código fuente para siempre.

### 5. Despliegue Automático (CI/CD)
GitHub se integra con plataformas como Vercel y Netlify para que cada cambio en el código se despliegue automáticamente en tu web en producción.
