**Figma** es la herramienta de diseño de interfaces más usada del mundo. El 80% de las empresas tech (Google, Microsoft, Airbnb, Uber) la usan para diseñar sus sitios web y aplicaciones antes de programarlas.

Y lo mejor: tiene un **plan gratuito** que cubre todo lo que necesitás para empezar.

---

## ¿Por qué Figma es importante para tu proyecto web?

Antes de escribir una sola línea de código, tu web o app debe diseñarse visualmente en Figma. Esto permite:

1. **Ver cómo va a quedar** antes de invertir en desarrollo.
2. **Hacer cambios baratos** (cambiar un diseño cuesta minutos; cambiar código cuesta horas).
3. **Validar con usuarios reales** usando prototipos interactivos.
4. **Alinear expectativas** entre vos (el cliente) y el equipo de desarrollo.

---

## Proceso de Diseño en Figma

### 1. Wireframes (Estructura)
Bocetos simples en blanco y negro que definen la distribución de elementos en cada pantalla. Sin colores, sin fotos, solo estructura.

### 2. Diseño Visual (UI Design)
Se aplican colores, tipografías, imágenes y estilo visual a los wireframes. Cada pantalla queda diseñada pixel por pixel.

### 3. Prototipo Interactivo
Se conectan las pantallas con interacciones (clics, navegación, transiciones) para crear una demo funcional que se siente como la app real.

### 4. Handoff al Desarrollador
Figma genera automáticamente las especificaciones técnicas (colores en código HEX, tamaños en píxeles, fuentes) que el desarrollador necesita para programar exactamente lo que se diseñó.

## ¿Necesitás saber diseñar para usar Figma?

No. Figma tiene miles de **templates gratuitos** y kits de componentes (botones, formularios, menús) que podés usar como base. Pero si querés un diseño profesional que convierta visitantes en clientes, lo ideal es que un diseñador UX/UI se encargue.
