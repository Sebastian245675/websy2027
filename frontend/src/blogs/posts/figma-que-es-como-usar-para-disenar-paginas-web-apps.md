**Figma es una herramienta de diseño que funciona en el navegador (y como app de escritorio) para diseñar interfaces de páginas web, apps y sistemas, crear prototipos navegables y trabajar en equipo en tiempo real sobre el mismo archivo.** Es el estándar de la industria para diseño de producto digital: diseñadores, desarrolladores y clientes ven y comentan el mismo diseño, y los desarrolladores obtienen de ahí medidas, colores y recursos.

En esta guía verás para qué sirve Figma, sus funciones principales, cómo se usa en un proyecto web paso a paso, cómo revisar un diseño si eres cliente y en qué se diferencia de otras herramientas.

## Para qué sirve

| Uso | Ejemplo |
| --- | --- |
| Diseño de interfaces | Las pantallas de una web, una tienda o una app |
| Prototipos | Versión navegable para probar el recorrido antes de programar |
| Design systems | Componentes y estilos reutilizables |
| Colaboración | Comentarios del cliente sobre el diseño |
| Entrega a desarrollo | Medidas, colores, tipografías e imágenes exportables |
| Lluvia de ideas | FigJam, la pizarra colaborativa |

## Funciones principales

| Función | Qué permite |
| --- | --- |
| Frames y auto layout | Pantallas y componentes que se adaptan al contenido, parecido a como se comporta en la web |
| Componentes y variantes | Piezas reutilizables con estados (botón normal, al pasar el cursor, deshabilitado) |
| Variables | Colores, tamaños y textos definidos una vez, con modos como claro y oscuro |
| Prototipado | Enlazar pantallas con interacciones y transiciones |
| Modo desarrollador | Ver medidas, estilos y código de referencia |
| Comentarios | Feedback sobre elementos concretos del diseño |

## Cómo se usa en un proyecto web

1. **Wireframes**: esquemas en gris de cada pantalla para acordar contenido y orden.
2. **Diseño visual**: aplicación de colores, tipografías e imágenes de la marca.
3. **Diseño responsive**: versiones para celular y computadora.
4. **Prototipo**: pantallas enlazadas para probar el recorrido en el teléfono.
5. **Revisión con el cliente**: comentarios sobre el diseño.
6. **Entrega**: el equipo de desarrollo implementa a partir del archivo.

Ver [qué es el diseño UX/UI](/blog/diseno-ux-ui-que-es-por-que-importa-para-tu-negocio).

## Si eres cliente: cómo revisar un diseño en Figma

- **Abre el enlace** que te comparten; no necesitas pagar para ver y comentar.
- **Prueba el prototipo** desde el celular (botón de presentación).
- **Comenta sobre el elemento concreto**, no en general: "este texto no se entiende", "falta el precio aquí".
- **Revisa con contenido real**: textos y fotos definitivos, no de ejemplo.
- **Agrupa los cambios** para cada ronda de revisión.

## Figma frente a otras herramientas

| Herramienta | Fortaleza | Comentario |
| --- | --- | --- |
| Figma | Colaboración en tiempo real, estándar de la industria | Funciona en el navegador |
| Sketch | Diseño de interfaces | Solo para Mac |
| Adobe XD | Diseño y prototipado | Adobe dejó de priorizar su desarrollo |
| Penpot | Código abierto | Alternativa libre |
| Canva | Piezas gráficas rápidas | No está pensado para diseño de interfaces complejas |

## Planes

Figma tiene un plan gratuito con límites de archivos y planes pagos por editor para equipos. Los que solo ven y comentan normalmente no necesitan un asiento pago. Las condiciones cambian; revisa la página de precios.

## Buenas prácticas para trabajar en Figma

- **Usar componentes y variables** desde el inicio, aunque el proyecto sea chico.
- **Auto layout** en todo lo que se repite, para que se comporte como en la web.
- **Nombrar capas y páginas** de forma clara.
- **Diseñar con contenido real**: textos y fotos definitivos revelan problemas que el contenido de ejemplo esconde.
- **Una página para el prototipo** y otra para los componentes.

## Preguntas frecuentes

### ¿Qué es Figma?

Una herramienta de diseño colaborativa que funciona en el navegador para diseñar interfaces de webs y apps, crear prototipos y trabajar en equipo sobre el mismo archivo.

### ¿Figma es gratis?

Tiene un plan gratuito con límites y planes pagos para equipos. Ver y comentar archivos compartidos suele no tener costo.

### ¿Figma sirve para hacer una página web?

Sirve para diseñarla y prototiparla. La web se programa después a partir del diseño, aunque existen herramientas que generan sitios desde diseños, con limitaciones.

### ¿Por qué diseñar en Figma antes de programar?

Porque cambiar un diseño es mucho más rápido y barato que cambiar código, y el prototipo permite probar el recorrido con usuarios reales antes de invertir en desarrollo.
